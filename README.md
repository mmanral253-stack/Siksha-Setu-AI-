# Shiksha Setu AI

A mobile-friendly educational demo website for Classes 6–8.

## Run locally
Open `index.html` in a browser. No build step or paid API is required.

## Publish on GitHub Pages (Android-friendly)
1. Sign in to GitHub and create a new public repository, for example `shiksha-setu-ai`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the website. The Pages screen will show the live URL.

## Demo limitations
- The Study Assistant uses predefined sample responses; no live AI service is connected.
- Quiz progress is stored in local browser storage on this device only.
- Feedback is validated in the browser but is not sent to a server.
- Lesson notes are sample learning content; add and review more curriculum-aligned lessons before formal use.
